# Quizkrutt

Separat, byggfri PWA-prototype (M1). Ingen avhengigheter eller konto.

Kjør `python3 -m http.server 4174 --directory dist` og åpne http://localhost:4174.
Service worker krever localhost eller HTTPS. Publiser hele dist-mappen.

Inneholder tre kategorier, 30 eksempelspørsmål, nivåvalg, ti spørsmål per runde,
fasit/forklaringer, poeng, omspill og bekreftelse ved avslutning. Høyere nivåer,
fremdriftslagring, pakkebibliotek og duell gjenstår.

Spørsmålene bruker stabile allmennkunnskapsfakta og egenformulerte forklaringer.
Innholdsredaksjon før en bred lansering gjenstår. Emoji varierer mellom enheter.
Fontene hentes valgfritt fra Google Fonts; systemfonter brukes uten nett.
Se MILESTONES.md. Fysisk installasjon på iPhone og Android må verifiseres separat.
