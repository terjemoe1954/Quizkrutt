## Description

Gi hjernen din litt konfetti!

Quizkrutt er en norsk quizapp for små pauser og store aha-opplevelser. Velg et tema, prøv tre nivåer og les korte forklaringer etter hvert svar. Ingen klokke jager deg.

• 540 spørsmål i grunnspillet, fordelt på seks kategorier.
• Tre nivåer: sju riktige av ti åpner neste nivå i samme kategori.
• Quizbibliotek med åtte pakker og 140 ekstra spørsmål, blant annet Historie og Mat og drikke.
• Last ned nye pakker uten konto, og spill dem senere uten nett.
• Sofaduell: to spillere bytter på samme iPhone eller iPad.
• Nettduell: spill fem felles spørsmål på hver deres enhet med kallenavn og romkode. Fasit vises når begge har svart.
• Pause og fortsett senere. Fremdriften lagres på enheten.
• Nullstill solo- eller pakkefremdrift, og behold nedlastede pakker og innstillinger.

Solo, lagrede quizpakker og sofaduell fungerer uten nett. Nettduell og nye nedlastinger krever internett. Ingen ChatGPT-konto eller passord kreves. Ingen annonser, abonnement eller kjøp i appen.

Grunnspillet har temaene Litt av alt, Verden rundt, Dyr og natur, Film og musikk, Sport og spill samt Vitenskap og teknologi. Fremdrift lagres separat på hver enhet og synkroniseres ikke.

Spørsmålene er egenformulert med KI-støtte og redaksjonell gjennomgang. Oppdager du en feil, kan du melde fra via supportsiden.

## Review notes (English)

Quizkrutt 1.0 is a Norwegian quiz app. No account, password or ChatGPT sign-in is required. No ads, purchases or subscriptions. Solo, six bundled packs and pass-and-play sofa duels work offline. Additional static JSON packs can be explicitly downloaded from GitHub Pages; no executable code is downloaded.

Online duels: on two devices open Nettduell, choose distinct nicknames, create a room on one and enter its eight-character code on the other. Five shared questions; answers and scores are revealed only after both reply. Backend: https://quizkrutt-online.terjemoe54.chatgpt.site. Access uses random per-player room credentials stored in Keychain, not accounts. Nicknames and gameplay data are processed for app functionality, without tracking. No chat or public room feed. Invites expire after 24 hours, rooms after seven days with bounded cleanup.

Settings includes progress reset, support and privacy. Full auditory VoiceOver support has not been claimed.
